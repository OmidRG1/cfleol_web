# CFLEOL — Canadian Forest Landscape Earth Observation Lab

Static single-page website for the CFLEOL research group at the Laurentian Forestry Centre, Canadian Forest Service, Natural Resources Canada.

## Live site

**https://omidrg1.github.io/cfleol_web/**

## Local preview

```powershell
cd cfleol_web
python -m http.server 8000
# open http://localhost:8000
```

Or simply double-click `index.html`.

## Structure

- Bilingual EN / FR (toggle button in nav)
